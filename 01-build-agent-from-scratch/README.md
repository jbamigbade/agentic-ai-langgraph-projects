# Build an Agent from Scratch

This project demonstrates the fundamentals of building an AI agent using OpenAI and Python.

## Overview

The agent follows the ReAct (Reasoning + Acting) pattern.

The workflow includes:

- Thought
- Action
- Observation
- Answer

The agent can:

- Maintain conversation history
- Select tools
- Execute actions
- Use observations to generate final answers

## Tools Implemented

### Calculator

Performs mathematical calculations.

### Dog Weight Lookup

Returns average weights for various dog breeds.
